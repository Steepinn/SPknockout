SPknockout

Knockout from lethal damage, rescue, self-revive, repeat-knockout cooldown, and a fully configurable config.yml.

Sections Overview Commands Installation config.yml Examples Troubleshooting

1 What the plugin does

SPknockout turns any lethal hit into knockout first when any-lethal-triggers-knockout is enabled (lava, void, mobs, players, etc.).

  • the player enters knockout instead of dying immediately;
  • an ally can revive them by sneaking nearby;
  • a knocked-out player can surrender with /die;
  • if nobody revives them in time, they die;
  • Quit while knocked out = same as /die (real death, loot, respawn).
  • Crawl mode (optional) — slow movement on the ground with a crawl pose while knocked out.
  • Repeat cooldown only after someone revives you (or self-revive) — blocked from another knockout for repeat-knockout-cooldown-seconds. Any death clears this; after respawn you can be knocked out again.

2 Commands

  • /die — only while knocked out; ends knockout with death.
  • /knockout reload — reloads config.yml without restarting. Permission: admin.reload-permission (default knockout.admin.reload).

3 Installation

  1. Copy the jar into the plugins folder.
  2. Start the server.
  3. Confirm plugins/SPknockout/config.yml was created.
  4. Edit config.yml for your server.
  5. Restart the server or run /knockout reload.

4 Full config.yml reference

language

  • locale — built-in message language: en or ru.
  • Default is English (en).
  • Override any string under messages manually if needed.

knockout

  • any-lethal-triggers-knockout — any lethal damage can trigger knockout (when not on repeat cooldown). If false, only player/mob entity hits use allow-mob-knockout; environmental kills skip knockout.
  • repeat-knockout-cooldown-seconds — lockout only after a successful revive. Death clears it. 0 disables.
  • crawl.enabled — crawl pose + lighter slowness so knocked-out players can move.
  • crawl.slowness-amplifier — slowness while crawling (used when crawl is enabled).
  • crawl.pose — Bukkit pose, e.g. CRAWLING (falls back to SWIMMING if invalid).
  • duration-seconds — knockout duration before automatic death.
  • rescue-seconds — time for a full revive.
  • horizontal-rescue-radius — rescuer detection radius.
  • rescuer-min-y-offset — minimum vertical offset for rescuer.
  • allow-environmental-damage-while-knocked — environmental damage in knockout.
  • allow-mob-knockout — mobs can trigger knockout.
  • allow-finisher-hit — players can finish knocked-out targets with hits.
  • team-only-rescue — only same scoreboard team can rescue.
  • post-revive-invulnerability-seconds — invulnerability after revive.

knockout.self-revive

  • enabled — enable self-revive roll.
  • chance — base chance (e.g. 0.25 = 25%).
  • chances.healing / chances.regeneration — per-potion-type chances.
  • consume-potion — consume a potion on success.
Requires a potion with base type HEALING or REGENERATION in inventory.

knockout.revive-health

  • mode: percent-max or fixed.
  • value: for percent-max — fraction of max HP (0.0–1.0); for fixed — HP.
  • minimum-hearts — minimum hearts after revive.

knockout.effects

  • slowness.amplifier, slowness.refresh-duration-ticks
  • blindness.amplifier, blindness.refresh-duration-ticks

messages

Use & color codes and {percent} for progress.

only-players no-permission not-knocked reload-success self-revive-success knockout-title knockout-subtitle rescue-reset-title rescue-reset-subtitle rescue-progress-title rescue-progress-subtitle rescuer-actionbar revived-title

visuals.rescue-particles

  • enabled, particle, every-ticks, count
  • offset-x, offset-y, offset-z, y-add

sounds.revive

  • enabled, sound, volume, pitch

admin

  • reload-permission — permission for /knockout reload.

5 Example configs

Hardcore

knockout:
  duration-seconds: 25
  rescue-seconds: 14
  horizontal-rescue-radius: 1.4
  allow-environmental-damage-while-knocked: true
  revive-health:
    mode: percent-max
    value: 0.30
    minimum-hearts: 2.0

Casual

knockout:
  duration-seconds: 90
  rescue-seconds: 7
  horizontal-rescue-radius: 2.2
  allow-environmental-damage-while-knocked: false
  revive-health:
    mode: percent-max
    value: 0.60
    minimum-hearts: 4.0

6 Troubleshooting

  • Knockout does not trigger — check damage source and plugin startup logs.
  • /die does nothing — only works while knocked out; command may be overridden.
  • /knockout reload — check admin.reload-permission and OP.
  • Rescue stuck — radius, rescuer sneaking, rescuer-min-y-offset, team-only-rescue.
  • No particles/sound — check visuals / sounds and valid Bukkit names.
  • Self-revive never fires — HEALING/REGENERATION potions and chance / chances.*.
